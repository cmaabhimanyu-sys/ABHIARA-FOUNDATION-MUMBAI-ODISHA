# Abhiara Foundation — Logo Theme Color Palette

Based on the official logo branding: "Fearless Ray of Light"

## Primary Colors

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Deep Green | Forest Green | #1B5E20 | Dark sections, footer, navbar top bar, headings |
| Medium Green | Green | #2E7D32 | Hover states, secondary elements |
| Light Green | Leaf Green | #4CAF50 | Badges, tags, success states |
| Deep Orange | Burnt Orange | #E65100 | Strong accent, important CTAs |
| Primary Orange | Amber | #F57C00 | Buttons, links, active states |
| Light Orange | Orange | #FF9800 | Highlights, icons |
| Gold/Yellow | Sunrise | #FFC107 | Warm accents, rays, decorative |

## Backgrounds

| Role | Hex | Usage |
|------|-----|-------|
| White | #FFFFFF | Main page background, cards |
| Cream | #FFF8E1 | Alternate light sections (warm) |
| Light Green Tint | #E8F5E9 | Subtle green sections |
| Dark Section | #1B5E20 | Hero, founder, CTA, footer |

## Text Colors

| Role | Hex | Usage |
|------|-----|-------|
| Heading | #1B5E20 | Headings on light backgrounds |
| Body | #333333 | Body text on light backgrounds |
| Muted | #666666 | Secondary text |
| On Dark | #FFFFFF | Text on dark green sections |
| On Dark Muted | rgba(255,255,255,0.7) | Secondary text on dark |

## Replacement Map (from current → new)

- #C9A84C (gold) → #F57C00 (orange) for accents/CTAs
- #B8942A (gold hover) → #E65100 (deep orange hover)
- #1B5E20 stays as primary dark green
- #2E7D32 stays as medium green
- #4CAF50 for light accents
- #E8F5E9 stays as light green tint
- #F1F8E9 → #FFF8E1 (cream warm sections)
- text-[#1B3A1B] → text-[#1B5E20] for headings
