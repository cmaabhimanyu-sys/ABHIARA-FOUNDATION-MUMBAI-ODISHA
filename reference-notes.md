# Reference Website Notes

## 1. Tree-I (treei.org/dashboard) — Live Impact Dashboard
Key features: Embedded live dashboard iframe, dark teal header, gold accents, transparency focus.
Top bar: "Section 8 · 80G & 12A · CSR-1 Registered". Clean serif headings.
Takeaway: Live impact dashboard showing real metrics, not just stories.

## 2. Bal Raksha Bharat (balrakshabharat.org) — Donation Page
Key features: Simple single-page donation with emotional child photo hero.
Donation form with PAN field for 80G. Impact banner showing "11 million children" stats.
Red/white color scheme. "DONATE NOW" sticky button top-right.
Takeaway: Simple, emotional, single-purpose donation page with trust badges.

## 3. Akshaya Patra (akshayapatra.org) — Special Occasion Donation
Key features: Tabbed donation types (Anganwadi, Honor/Memory, Special Occasion, Wire Transfer, SME, Sponsor School, Sponsor Kitchen).
Occasion donation: Choose occasion (Birthday/Diwali/Anniversary/Achievement), pick e-card template, enter honoree details, send greeting card with donation.
Amount grid: Rs 4500-201000 with "feeds X children for 1 year" impact mapping.
Takeaway: Multiple donation types, occasion-based giving with e-cards, impact-per-rupee mapping.
